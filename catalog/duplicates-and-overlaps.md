# Duplicates and overlaps

When several skills solve the same problem, one is chosen as the
`recommended` default (workflow quality, scope, maintenance) and alternatives
are kept only when they take a meaningfully different approach. This file
records those decisions so they are not silently re-litigated.

Format per decision: the overlapping skills, what was compared, which one is
the default, why, and what happened to the rest (kept as alternative,
rejected, superseded).
